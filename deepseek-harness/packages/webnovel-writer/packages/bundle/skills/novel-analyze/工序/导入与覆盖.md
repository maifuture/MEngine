# 导入与覆盖

## TXT

1. 先识别 BOM 和严格 UTF-8。
2. 无法确定编码时，请作者明确是 utf-16le、utf-16be、gb18030 还是 big5。
3. 编码预检不返回原文示例。不要用替换字符继续分析。
4. 内部阅读单元的身份不同于显示章号。
5. 以下情况都看问题清单，不猜补缺章：
   - 重复目录；
   - 卷内章号重置；
   - 缺章；
   - 没有可靠的章界。

## EPUB

1. 按 spine 的实际阅读顺序处理。目录锚点形成阅读单元。
2. 保留非 linear 内容和脚注定位。
3. 以下情况如实报错：正文加密、损坏 ZIP、目录越界、DTD、超限、不可解析的正文。
4. 字体混淆不等于整本 DRM。
5. 只有能读取文字的范围参与分析。图片正文或遗漏的资源不称为已读。

## 预检、导入与覆盖

1. 主聊天预检只返回索引与问题。
2. 导入建立版本化的本地副本。用户原文件只读。
3. 字节和解析设置都相同时，复用已有版本。
4. 变版、缓存损坏、取消与中断：
   - 不能清空已验证的结果；
   - 不能越过缺口标为完成。
5. 覆盖率字段：

   | 字段 | 含义 |
   |---|---|
   | status 的 covered | 按不重叠的字符区间计算 |
   | allReadableTextCovered | 只表示可读文字已全部覆盖 |
   | fullBookEligible | 还要求没有阻塞缺口 |

6. 实际报告由 build 生成后再交付。不要把已有的旧报告当作当前完成状态。
