# 批次 2:节奏与重塑(合并：句段节奏＋对话润色＋修辞与意象；文风契约为总判据)

> 《精修润色》批次参考文档。本批是**结构性与表达力改写**:跨段判断、重写句段。总判据是《作品契约》「叙事方式与文风基调」分部——一切改写向它对齐；每条操作仍受保真边界约束:**信息与因果不动**。

## 按需保真核对

只核对当前片段相关的项，不逐条套用、不另起一轮审读；每处修改须对应具体原文问题。
- **信息来源与确定程度**：谁知道、怎样知道、确定到什么程度；推测不变事实、听说不变亲见、人物判断不变叙述者确认。“也许／才／又／据说”等先确认作用再动。
- **指称、否定与时间关系**：省略前确认行动者唯一、话题连续；换人、对比、多人互动处保留必要点名。否定作用域、条件、先后与同时关系、意图强度不得改变，如“没打算”不等于“不想”。
- **对白言语行为**：人物共同知识与读者知识分开判断；求证、拒绝、承诺、提醒、施压等作用不变，不删有功能的重复，不为潜台词改换意图。也不引入原稿声音里没有的书面腔。
保护的是含义，不是冻结词面；原有身体反应、直接心理叙述、叙述者概括都可以有效，不因常见而删除或以新动作替换。
无问题就回传“本批无修改”，不写无差异版本；有代表性保留项时简述理由，不凑数量。拿不准时保留并标注，未决保真风险不等于检查通过。

## 第一节 句段节奏

| 手段 | 用在 | 做法 |
| --- | --- | --- |
| 短句化 | 需要加速的动作场面 | 按效果调整句长，保留必要修饰；不规定每句一个动作 |
| 独立成段 | 爆点、转折、宣判 | 关键一句单独成段，前后留白 |
| 长句铺陈 | 心理、环境、战后休整 | 根据文风舒展节奏，不凭固定信息点数量切句 |
| 段落呼吸 | 全章 | 按语义和阅读负担分段，屏幕行数不作统一标准 |
| 句式变化 | 无意机械重复处 | 可调整句式；有意排比和复沓保留，不补造动作 |

“蓄—放—收”可以帮助分析节奏，但不是每场戏的必需结构。依据本章目标判断张弛和收束；需新增情节才能改善时记审读，不在润色中硬造呼吸窗、转折或钩子。

## 第二节 对话润色

- **人物声音**：依据已给档案和原文观察句长、称呼、口头习惯与表达方式。不按职业或身份刻板规定说法，不凭空添加口头禅；
- **对话作用**：检查台词是否符合人物目的、关系和知情范围；已有的解释或意见一致可以成立，不为制造冲突把同意改成反对，也不删除有意的劝说或背景交流；
- **标签与动作**:说话人明确时可省略多余的「说道/回答道」，或与原文已有的伴随动作衔接；说话人不明时保留必要标签，不为删标签新增动作事实。省略标签不等于删对话引号。长对话的动作/微表情拍点按语境核对，不机械补造；
- **潜台词**：原文已有回避或言外之意时可改善表达；明确回答同样合法，不能把直说改成隐瞒、改变人物决定或增加未写出的心理动机；
- 语气词按人物定制、总量克制；方言/古语只给特定人物；现代流行语出戏时交作者裁决。

## 第三节 修辞与意象

- **比喻取舍**：按本书文风与上下文判断是否准确、有效；必要时等义调整，不能因常见就一律删除。新比喻只作修辞，不引入世界规则或实体事实；
- **意象连贯**：利用原稿与已给材料中的意象改善呼应，不强制每章新增母题或轮换五感；
- **密度判断**：看修辞是否妨碍动作、信息或情绪，允许作者选择疏密不同的文风，不设跨作品统一数量上限。

## 文风贴合(本批总判据，不单独立步)

1. 先读契约文风分部原文，列 3–5 条可核查特征(短句/少成语/疏离感等);
2. 本批每次改写后对照特征清单。时代违禁词(非现代背景出现现代专有词)换时代内表达或交作者裁决；
3. 作者声音全章连续，单段无依据的突兀换挡拉回。场景之间叙述距离与快慢的合理变化(动作、回顾、说明、对白)不算漂移，不抹平。以契约「叙事方式与文风基调」分部与材料包文风段为准。**想加契约没写的文风偏好→作为建议呈作者，写入契约才算数**。

## 批次自查清单

1. 每个改写句：信息与因果与原句等价？
2. 对话：说话人、次序、决定、信息内容未变？
3. 比喻：未引入世界书没有的设定事实？情绪方向未反转？
4. 作者声音连续？场景间合理的语体变化未被抹平？

## 保真边界

- 只动表达与结构组织：不增删情节/人物/道具/设定；对话内容与顺序不变；
- 直接引语与转述可以共存，沿用作者已有的合法引号体例。不能以去 AI 味、格式统一或某种形式占多数为理由，删对话引号、改变人称或改成转述；需要改变叙述方式时交作者决定；
- 快慢判断依据情节性质，不凭口味重排段落顺序；
- 比喻不引入新设定；拿不准→保留＋标注。
