# 财报研判分析手册

本文件是 SKILL.md 的配套参考。只在需要「怎么定级」「矛盾怎么查」「前瞻怎么推」时读。

**适用范围**：本手册的方法只用于业绩预告、季报、半年报、年报及其摘要——默认是默认窗口（当日 + 上一交易日）内披露的那份；用户明确要求最新数据时，也适用于最近一份（此时定级要注明「已披露 N 天，市场已完成首轮定价」）。评级对象是这份文件本身，不是某条公告，也不是这家公司整体。回购、增减持、重大合同、诉讼等非定期披露类公告的研判，不适用本手册。

---

## 一、五级评级：定义与判定顺序

只输出五级中的一个词，不给区间、不写「偏正面」「谨慎乐观」。

| 评级 | 判据 |
|---|---|
| 重大利好 | 有量级事件 + 直接改变盈利中枢 + 市场首日强反应（放量大涨） |
| 利好 | 实质正向增量，但量级有限或兑现有时滞 |
| 中性 | 无信息增量 / 多空对冲 / 程序性文件 |
| 利空 | 实质负向增量，或预期差为负 |
| 重大利空 | 触及持续经营、控制权、退市、重大处罚等 |

**判定顺序（不可跳步）：**

1. **信息增量**：市场是否早已知道？股东会决议、法律意见书、章程修订属于「已知议案的确认件」→ 中性。业绩预告若已在前期指引区间内 → 中性。
2. **二阶导**：环比与增速的变化方向，优先于同比绝对值。同比 +66% 但环比失速，比同比 +20% 但环比加速更差。
3. **利润归属**：归母 vs 扣非 vs 经营现金流，三者是否同向。背离时以扣非和现金流为准。
4. **事件时钟**：「拟」「提议」「尚需审议」「获批」都不等于「已实施」。实施日在数月后的，短期效力大幅折价。
5. **市场投票**：公告后可交易首日的涨跌幅与量能。字面方向与走势相反时，去查预期差与筹码结构，不要强行自圆其说。

**业绩预告的降级规则**：预告没有环比、没有现金流，上面第 2、3 步只能做一半。此时按下面三条补：

- **第 2 步**只看同比本身，外加**区间宽度**——跨度超过中值 30% 的，实质是公司自己承认看不清，评级向中性收敛一档。
- **第 3 步**用「归母 − 扣非」的区间代替现金流判断。差额占归母比重高（>30%）= 利润主要靠非经常性损益，评级打折。
- **预告不得给「重大」级**。除非区间下限本身就指向盈利中枢的量级跃迁（如从亏损到数十亿盈利），否则最高只给「利好」或「利空」——未经审计的区间值撑不起「重大」。若标题带「暨风险提示」，风险段的量级可以直接压低一档。

## 二、利润质量三问（每次必做）

拿到「净利润转正」这类表述，先拆三刀：

**第一刀：归母 − 扣非 = 多少？**
差额就是非经常性损益。查它由什么构成：

| 构成 | 可持续性 | 现金含义 |
|---|---|---|
| 政府补助 | 中（常有但不稳定） | 有现金 |
| 金融资产公允价值变动 | 极低，随市场波动 | **无现金** |
| 处置资产/股权收益 | 一次性 | 有现金但不可重复 |
| 债务重组/诉讼赔偿 | 一次性 | 有现金 |

公允价值变动占比超过 50% 时，写「净利转正的主要来源与主业无关」。

**第二刀：扣非净利率是多少？**
低于 1% 就是「贴水面」，一次原材料涨价或减值就能打回负数。这种转正要明确写「薄」。

**第三刀：经营现金流 ÷ 净利润 = 多少？**
长期低于 1，说明利润没有变成钱。要解释钱去哪了：应收、存货、预付款、保证金。若公司用「备货」「产能保证金」解释，追问一句「这笔钱什么时候能回来」。

## 三、内部矛盾六查清单

同一份报告里前后不一致，是最有价值的发现。按下列六类逐条对读：

1. **时间窗口选择**：是否用「单季转正」覆盖「半年仍亏」？用「同比改善」掩盖「环比恶化」？
2. **上下游对称性**：说需求旺盛、订单增加时，看合同负债（下游锁定）与预付款/保证金（上游锁定）是否同向。**上游锁得狠、下游锁得松，是需求判断不牢的强信号。**
3. **归因模糊**：把「A+B 增长」笼统归为单一原因，而 A 与 B 实际方向相反（例：储能好、国内光伏差，统称「光伏储能增长」）。
4. **动作自相矛盾**：一边大举备货、一边加速计提跌价；一边说精益提效、一边某项费用暴增。方向相反的动作要指出。
5. **风险提示的量化缺失**：承认了商誉/存货风险，但没给敏感性分析或关键假设。
6. **非经常项藏在哪**：是否把一次性收益放在正文叙述的显眼处，却把扣非亏损放在角落。

写这类发现时，**必须注明「这是叙事张力，不等于财务造假」**，避免误导。

## 四、前瞻三指标：谁有效、谁无效

不要机械套用「合同负债增长＝未来收入好」。先判断商业模式。

### 合同负债

| 商业模式 | 预测力 |
|---|---|
| 预收款/会员/订阅/工程承包 | 强。合同负债直接对应未来确认的收入 |
| 经销为主 + 账期销售（多数芯片、元器件、消费品） | **弱**。常年占营收 1%~2%，波动即噪声 |

对弱预测力行业，只读**方向**不读幅度：连续多期向上 = 订单未断崖；单期下滑不足以定性。

### 应收账款

必算两个数：

- **周转天数** = 平均应收账款 ÷ 期间营收 × 期间天数
- **增速对比**：应收增速 vs 营收增速

判据：**营收增速 > 应收增速，且周转天数下降 = 增长质量过关**（不是靠放宽账期换收入）。反之要警惕。

再看账龄：1 年以内占比 95% 以上为干净。注意坏账计提比例是否统一固定（如一律 5%）——统一比例对客户结构恶化不敏感，需额外提示。

### 存货

三个数一起看：

- 存货账面余额增速 vs 营收增速
- **跌价准备计提率**（跌价准备 ÷ 账面余额）的变化方向
- 存货 ÷ 期间营业成本 × 期间天数 = 可支撑月数

判据：备货扩张但计提率同步抬升 = 公司在赌需求，同时承认部分货在贬值。**这两个动作方向相反，下一期财报会揭示哪一头错了。**

## 五、单季推演：边际利润法

不要用「去年单季 × (1+增速)」拍脑袋。用 Q2 的实际边际数据外推：

```
下季营收 = 本季营收 × (1 + 环比假设)        # 假设来源：历史环比区间、产能/库存条件
边际毛利 = 营收增量 × 毛利率假设
边际费用 = 研发+销售+管理的增量（通常远低于收入增速）
下季扣非 ≈ 本季扣非 + 边际毛利 − 边际费用 − 税费
```

**必须做区间，不给单点。** 归母要给更宽的区间，因为公允价值变动等外生变量不可预测。

推演要标注三件事：① 公司是否发布过指引（多数不发）② 假设的具体数值 ③ 误差来源。

同时写**反方论证**：如果结论错了，最可能错在哪个假设上（毛利率已见底？费用率还能降？某新业务超预期？股价已提前反映？）。只写支持结论的证据是失职。

## 六、常见陷阱

- 只读标题定级，不读原文数字。
- 把「同比暴增」直接判利好，不看单季环比与价格趋势。
- 把股东会决议、法律意见书说成利好或利空。
- 用披露日当天的行情解释周末公告的影响（周末公告看下一交易日）。
- 声称「窗口内无公告」却没用全市场同日公告量做反证。
- 把 H 股例行披露（翌日披露报表、证券变动月报表）当新增事件。
- 用「PE 高」单独下结论，不结合增速与利润质量。
- 推演只给一个数，不给区间与假设。

## 七、A+H 与科创板的技术坑

- **A+H 公司**：公告列表混入大量 H 股披露（翌日披露报表、月报表、董事会会议日期）。这些多为同步信息，不算新增事件。但「董事会会议日期」是**唯一能提前锁定定期报告披露日的线索**，必须抠出正文日期。
- **H 股公告 PDF 编码**：常为繁体 + 文本层编码错乱，中文变乱码，阿拉伯数字仍在。抠日期用宽松正则，并用「日期必晚于公告发布日」做逻辑校验（落款日必在其前，可自动排除）。
- **科创板季报**：部分公司的季报未被 cninfo 归入 `category_yjdbg_szsh`，按类别查会漏。必须用标题正则兜底。
- **标题用词不统一**：「第三季度报告」/「三季度报告」/「2026年度报告」/「2026年年度报告」都存在，正则要把「第」和「年」都写成可选。
- **PDF 表格是图片**：分产品收入表、毛利率表常为图片，文本层提取不到。遇到时在报告里明确标注「该表未能提取」，不要编数。
