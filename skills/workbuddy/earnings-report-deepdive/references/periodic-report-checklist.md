# 定期报告阅读清单

出现季报、半年报或年报时（默认当日披露；用户明确要最新数据时取最近一份），按本清单逐组抄数字。**禁止只读标题或摘要就下判断。**

> **业绩预告、业绩快报不适用本清单。** 它们没有附注、没有资产负债表、没有现金流量表，下面七组里有四组抄不到。这两类改用 SKILL.md 3.2 的区间打法：取中值、算同比三档、看扣非剪刀差、读风险提示段。别拿着这份清单去凑数。

顺序有讲究：先抄主表，再挖附注，最后读管理层讨论。倒过来容易被公司的叙事带着走。

---

## 1. 主要会计数据（第二节开头）

必抄：营业收入、利润总额、归母净利润、扣非归母净利润、经营活动现金流净额、归母净资产、总资产、基本每股收益、加权平均 ROE、研发投入占营收比例。

**为什么先抄这组**：它决定后面所有比率的分子分母，也是公司最想让读者看到的一组数字。先自己算出比率，再去看管理层怎么解释，可以避免被解释框架牵着走。

同时抄「上年同期」整列——同比要用。

---

## 2. 非经常性损益明细表

必抄：每一项的金额 + 合计 + 所得税影响 + 少数股东影响。

重点看四项：政府补助、金融资产公允价值变动及处置损益、非流动资产处置损益、其他营业外收支。

**判断**：金融资产公允价值变动占非经常性损益的比例。超过 50% 时，这个利润是市场给的，不是经营赚的，且**不产生现金**。

---

## 3. 合并利润表关键行

必抄：营业总收入、营业成本、税金及附加、销售费用、管理费用、研发费用、财务费用（含利息费用/利息收入）、其他收益、投资收益、公允价值变动收益、信用减值损失、资产减值损失、营业利润、利润总额、所得税费用、净利润、归母净利润、少数股东损益。

**必算**：

- 毛利率 =（营收 − 营业成本）/ 营收
- 期间费用率 =（销售 + 管理 + 研发）/ 营收
- 财务费用率 = 财务费用 / 营收

**找异常项**：某一项费用增速显著高于营收增速（例：财务费用 +609%），单独拎出来，去管理层讨论里找解释。

---

## 4. 资产负债表关键项（资产及负债状况表）

必抄本期期末数、上年期末数、占总资产比例、变动比例：货币资金、应收款项、合同资产、存货、长期股权投资、固定资产、在建工程、短期借款、合同负债、长期借款、租赁负债。

再抄总额：总资产、归母净资产、商誉。

**判断**：借款增加是否对应特定用途（例：为支付产能保证金借入专项借款）。有用途说明的负债，风险性质与无用途的补流不同。

---

## 5. 附注深挖（最容易被跳过，但含金量最高）

| 附注 | 抄什么 | 为什么 |
|---|---|---|
| 应收账款按账龄 | 各账龄段余额、合计 | 1 年以内占比 >95% 为干净 |
| 应收账款按坏账计提方法 | 组合计提比例、单项计提金额 | 统一固定比例（如一律 5%）对客户恶化不敏感 |
| 存货分类 | 库存商品/原材料/委托加工/在产品/合同履约成本 各自的账面余额与跌价准备 | 算分类计提率，找出哪类在贬值 |
| 存货跌价准备变动 | 期初、本期计提、转回或转销、期末 | 计提率变化方向比绝对额重要 |
| 预付款项 | 账龄、前五名占比 | 突然增大可能是锁产能或预付货款 |
| 一年内到期的非流动资产 / 长期应收款 | 是否有保证金、返还安排 | 大额保证金是一个独立风险敞口 |
| 所有权受限资产 | 受限金额与原因 | 货币资金里有多少是不能动的 |
| 商誉 | 金额、对应资产组 | 占净资产比例决定减值杀伤力 |

---

## 6. 管理层讨论与分析

按「收入 → 成本 → 费用 → 现金流」四条线读，每条都要找到公司的原话解释，再与第 3 组算出来的数对照。

重点摘录：

- 收入变动的三个原因（需求端 / 产品端 / 市场端）——是否给了量化拆分，还是只有定性描述
- 成本变动原因——是否提到原材料涨价、产品结构变化
- 各费用变动原因——财务费用异常时看是否归因汇兑
- 现金流变动原因——经营现金流转负时，钱去了哪里（应收/存货/保证金）
- 下游应用或分产品的收入结构占比及同比变化
- 风险因素章节——公司自己承认了什么，有没有量化

**这一节是矛盾检查的主战场**：把这里的表述与前面的数字逐条对读。

---

## 7. 分季度数据

年报通常披露分季度营收与归母；半年报披露 Q1、Q2。季报只有单季与累计。

若报告未披露分季度，用「本期累计 − 已披露的上期累计」倒算：

- 半年报的 Q2 = H1 − 一季报
- 年报的 Q4 = 全年 − 三季报累计

**必做**：画一条分季度营收与归母的序列表。看收入曲线与利润曲线是否同步——不同步的地方，就是这家公司当下的核心矛盾。

---

## 8. 抄不到的数据怎么办

季报通常没有完整附注（应收账龄、存货分类、合同负债明细都拿不到）；部分 PDF 的表格是图片，文本层提取为空。

处理原则：

1. 换时点，不要硬编。季度序列拿不到，就用半年报与年报的两个时点做年度对比，并在报告里写明「季度频率不可得」。
2. 图片型表格在报告里明确标注「该表未能提取」，不猜数字。
3. 必需但缺失的数据，用「未披露」而不是空白或 0。
