# 公告影响五级评级框架

评级回答的是一个很窄的问题：**这份公告，对这只股票未来 1~5 个交易日的价格，边际影响是正、负还是零？**
它不预测长期价值，也不预测点位。所有判断必须能落回公告原文与行情数据。

## 一、五级锚点

| 评级 | 幅度锚点（相对公告后可交易首日） | 含义 |
|---|---|---|
| 重大利好 | 单日 +7% 以上，或连续多日累计显著上行 | 改变盈利预期或供需格局，非一次性 |
| 利好 | +2% ~ +7% | 有实质正向信息，但幅度有限或部分已被预期 |
| 中性 | -2% ~ +2%，或方向无法判定 | **无信息增量**，或正负相抵 |
| 利空 | -2% ~ -7% | 实质负向信息，幅度有限 |
| 重大利空 | -7% 以上 | 击穿核心逻辑：盈利预期大幅下修、治理/合规硬伤、流动性冲击 |

幅度锚点仅作校准参考，不是承诺。科创板/创业板 ±20%，主板 ±10%，ST ±5%，锚点需按板块缩放。
**评级针对"公告的边际影响"，不针对"股票好不好"。** 一只票可以基本面极佳而公告评级为中性。

## 二、判定顺序（严格按序，前面的能一票定调）

### 第 1 步：信息增量检验——这是最容易错的一步

对公告逐条问四个问题：

1. 这条信息，市场**在此之前**是否已经知道？（股东大会决议、法律意见书、核查意见、章程修订，通常都是"已知议案的确认件"）
2. 首次披露距今多久？超过 5 个交易日，基本已消化。
3. 公告是否包含任何一个**新的数字**？（金额、增速、价格、比例、时点）
4. 与市场一致预期相比，这个数字是超、平还是低？

**若四个问题都指向"无新增信息"，直接定为中性，不必再往下走。**
此时不要为了显得有观点而强行找出利好利空——"中性"就是正确答案，且必须写明"中性是因为无信息，不是因为多空平衡"。

### 第 2 步：是否已被定价——看公告后可交易首日

- 用 `quote_snapshot.py --align <披露日>` 定位**首个交易日**。
- 周末/节假日披露的公告，市场反应整体推迟到下一交易日，绝不能按披露日当天的行情归因。
- 若公告前股价已连续大涨/大跌，且公告当日冲高回落或低开高走，说明**已被提前定价**，实际影响应下调一档甚至两档。
- 量能是判据：放量滞涨/放量下跌 = 分歧兑现；缩量上涨 = 抛压小但接盘也少。

**关键校核：如果"公告字面方向"与"首日实际走势"相反，以走势为准来解释，而不是坚持字面。**
必须去找出走反的原因（见第五节），而不是把下跌硬解释成"利好"。

### 第 3 步：二阶导优先于绝对值

市场给成长股定价的是**变化率的变化率**。
净利润同比 +8 倍是"过去"；单季环比从 +113% 掉到 +3% 是"未来"。后者才是定价依据。
同类情形：毛利率环比见顶、订单增速放缓、价格涨幅收窄、产能利用率下滑——哪怕绝对值仍在历史高位，也应判为利空或压制评级。

### 第 4 步：五渠道打分

| 渠道 | 要问的问题 | 权重 |
|---|---|---|
| 盈利预期 | 对当年/次年净利的量化影响是多少 %？ | 高 |
| 信息增量 | 是否有市场未知的新事实？ | 高 |
| 资金/筹码 | 是否改变供需：回购、增减持、解禁、融资？ | 中 |
| 当期财务 | 短期是否增加成本/折旧/费用而不产生收入？ | 中 |
| 治理/合规 | 是否触及立案、处罚、退市、控制权变更？ | 低（除非命中硬伤） |

多数公告只在 1~2 个渠道有分，其余为零。**不要把五个渠道都勉强凑出一条理由。**

### 第 5 步：强制反方论证

定稿前，必须写出"如果我的评级是错的，最可能错在哪里"，一句话即可。
写不出反方理由，说明论证不完整，不是结论太确定。

## 三、事件时钟：区分三个时点

同一件事有四个日期，混淆就会误判：

1. **披露日**——公告刊登日，可能是非交易日
2. **首个可交易日**——市场第一次能反应的日子（用 `--align` 求）
3. **审议/生效日**——董事会、股东会通过
4. **实际执行日**——真正发生资金/股份/产能变动的日子

**"提议""拟""尚需审议""获批"都不等于"已实施"。** 若实际执行日在数月之后（例如回购常附"上市满 6 个月后方可实施"、募投项目有 30 个月建设期），则该公告对短期股价的托底/压制效力必须大幅折价，只能作为情绪信号记入。

## 四、常见陷阱（实战验证过）

| 表面 | 实质 | 正确处理 |
|---|---|---|
| 业绩预增 X 倍 | 若单季环比失速，属"利好出尽" | 看环比与价格涨幅趋势，常判中性偏空 |
| 股东会决议公告、法律意见书、核查意见 | 纯程序确认，无新信息 | 中性；除非有议案被否、议案被修改 |
| 董事长提议回购 10~20 亿 | 占市值 < 0.1%，且未实施 | 忽略量级，仅记情绪；写明实施前置条件 |
| 关联交易额度上调 | 多因涨价，属回溯性信息 | 中性；可作为下游需求/价格的旁证 |
| 超募资金投建新项目 | 长期扩产正面，短期只有折旧费用 | 短线中性，长线偏正；注意建设期 |
| 高送转、更名、迁址 | 无现金流影响 | 中性 |
| 象征性增持（几百万至几千万） | 市值管理信号 | 中性，最多微正 |
| 解禁公告 | 视规模/流通市值比而定 | 比例 >10% 且股价高位 → 利空 |

## 五、当"字面"与"走势"背离时，去查这四件事

1. **预期差**：市场此前预期是多少？公告是低于还是高于预期（而不是同比多漂亮）。
2. **同业与海外联动**：同板块、海外对标标的当日涨跌，常常比公司公告更能解释走势。
3. **拥挤度**：前期涨幅、换手率、融资余额、机构持仓集中度。获利盘厚则利好即出货窗口。
4. **结构性漏损**：归母 vs 净利总额、少数股东损益、母公司持股比例、一次性损益。

用 WebSearch 交叉验证当日财经媒体的归因，**但不要直接采信**——媒体常把下跌原因写成"利好出尽"了事，要自己用数据验证（环比、价格、量能）。

## 六、输出要求

- 明确给出五级评级中的一个，不给区间、不用"谨慎乐观"之类的模糊词。
- 评级后面必须跟三件东西：① 定级理由（1~3 条，可验证）② 反方风险 ③ 真正的驱动变量（公告之外该盯什么）。
- 涉及数字必须标注来源与口径（公告原文 / 行情接口 / 媒体二手）。
- 对"昨日今日无公告"或"只有程序性文件"的情形，如实说明，并主动把窗口扩大到 10 天以上，检查是否有周末披露的重磅公告被"昨日"这个口径漏掉。
